# Photo Metadata Writer

Local browser app for batch photo metadata editing.

## Features
- Upload multiple photos at once.
- Apply batch metadata across all photos (location, date/time, attribution/credit, and more).
- Override metadata on individual photos.
- Bulk rename outputs with prefix/suffix/sequence controls.
- Optional per-photo custom output filename.
- Download one edited photo or all edited photos as a ZIP.
- Export all metadata as CSV.

## Run
```bash
npm install
npm run dev
```
